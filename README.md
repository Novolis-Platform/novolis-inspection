# novolis-inspection

UI-independent inspection documents for complex data. Avalonia, Blazor, CLI, and future tooling can render the same tree.

## Packages

| Package | Purpose |
|---|---|
| `Novolis.Inspection` | Inspection document and tree contracts |
| `Novolis.Inspection.Json` | JSON formatter |
| `Novolis.Inspection.Xml` | XML formatter |
| `Novolis.Inspection.Http` | HTTP message formatter |
| `Novolis.Inspection.ObjectGraph` | Reflection object graph formatter |

See [getting started](docs/getting-started.md), [design](docs/design.md), and [release](docs/release.md).
